# CineTrack — Interactive Fastify Architecture Explorer

A guided tour through the real CineTrack backend — not slides.

**Question → Architecture → Real code → Explanation → Takeaway**

## Run

```bash
cd presentation
npm install
npx ng serve --port 4200
```

## Controls

| Key | Action |
|-----|--------|
| → / Space | Continue |
| ← | Back |
| A | Architecture focus |
| C | Code focus |
| F | Focus explanation |
| S / Split | Split view |

Chapter chips jump to any section. Code viewer highlights the relevant CineTrack lines.
